I was in middle school when I first encountered HTML. I had a friend named Jeff who was into computers and had a dad who was quite knowledgeable about the stuff. Jeff knew DOS and could get things to work when something was broken. I don't know how we started talking about HTML exactly, but it came after we had made a thing we called the Band Book. 

It was literally a 3-ring-binder that we filled with things printed from the library. This included song lyrics, band trivia, and other stuff like that. I didn't have a computer at home so one of the early was I was able to get online was going to the public library and using their computers.

So back to the HTML. We had the book but it lived in whosever backpack it ended up that week. I think we wanted to have something that was accessible to both of us kind of whenever. I'm paraphrasing some of this from my own minds reconstruction of those days, but it was probably something like, "well, there's this code stuff that we could write and we could put it online and we'd be able to see it". We then spent a couple of lunchtimes sitting outside the hallway of our orchestra room with him writing tags out on a lined paper.

"It always has to start with an angle bracket. The first thing has to say `<html>`. Then you have to have one at the end that has a slash which means that it's the end of that part."

This was fascinating to me. Writing some lines in a text editor and opening the file in a browser (Netscape Navigator FTW!) was crazy cool to see. We could change the font size, font colour, manipulate it a bunch of different ways. This was before stylesheets so it was all inline. I took a look at the source code of site we made, it's still on the Wayback Machine. There were lots of `<center>` tags and we did font size increases with `size=+2`. It was a wild time. 

Every couple of days I'd think of stuff to add. We had a logo that I did in Paint, and of course we had crazy GIFs and weird banner stuff going on. I'd ride my bike down to the library and open up notepad. Type out the file and upload it to Geocities. A page refresh later and I'd see if I had made any mistakes or if it was like it was supposed to look like. Sometimes I'd miss a closing tag, sometimes there was an issue with one of the links we pasted in for getting band images into our page. It was always exciting seeing it all come to life though. 

I think we gave up on it after a couple of months. It might have been one of those things that fizzled out over the summer, i don't remember. I'd come back to writing HTML and CSS here and there. Adding scripts when I wanted to have a little extra firepower but I kind of kept it all on the back burner. For one, I didn't think I had patience or smarts to work with computers. That's maybe for another post. 

Anyway. It's interesting to see how long we've come from the mid to late 90s. How much is the same and how much has changed.
